## Generate an energy grid using DFT

NOTE: This example is old, and might not run error free in the
current version. Nevertheless, it highlight one way of 
defining custom calculators and runscripts using the framework
of the sampler code and ase calculators.

1. Run single point calculation in `single_point_calculation/`
2. Adjust `grid_gen.py`
3. Run `submit.sh`
