# Example of how batch sampling works

This folder contains an example of how the batch sampler can
be used.

1. 54189.cif is the cif-file containing the structure to be sampled.
2. runscript.sh is the script that can be run (with bash) to run the batch 
sampler.
3. analyze\_batch\_script.sh is a runscript for the batch analyzer
(analyze\_batch.py), that can be run after a succesfull batch sampling,
to compile the energy grid.
